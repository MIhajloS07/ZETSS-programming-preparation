# ZETSS Programming Competition Preparation

This repository contains my C++ solutions, exercises, and personal notes created during my preparation for the Republic Programming Competition organized by ZETSS.

## About the Project

The goal of this repository is to document my preparation process, strengthen my programming skills, and organize solutions to programming exercises in one place.

The repository focuses on algorithmic thinking, problem-solving, and practical implementation in C++.

## Contents

- **Programming Exercises** — solutions to exercises organized by topic.
- **Algorithms** — implementations and practice problems related to algorithms.
- **Problem-Solving** — solutions accompanied by explanations of the approaches used.
- **Study Notes** — personal notes and summaries, where applicable.

## Technologies

- C++
- Git
- GitHub

The original study materials and personal notes are primarily in Serbian.
